# django-hit237-2026-week2-practicals
HIT237 week 2 practical session

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/django-hit237-2026-week2-practicals.git
   cd django-hit237-2026-week2-practicals
   ```

2. Create a virtual environment:
   ```
   python -m venv venv
   ```

3. Activate the virtual environment:
   - On Windows: `venv\Scripts\activate`
   - On macOS/Linux: `source venv/bin/activate`

4. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

5. Initialize the database:
   ```
   python manage.py migrate
   ```

6. Run the development server:
   ```
   python manage.py runserver
   ```

7. Open your browser and go to `http://127.0.0.1:8000/` to see the Django welcome page.
